# Episode - 1 (DevTinder)
## How to Build a Project
* Here we are going to discuss waterfall model.
* There are 7 phases in waterfall model.

```
- Requirements
   - Design
      - Development
        - Testing
           - Deployment
              - Maintenance

```
### Requirements Gathering
* It is all about the collecting essential requirements which are essential for the project.

* This is decided by the Product/Project Manager by working with designers like webframing of whole project with requirements.
* what features
* what is going to build
* How we are going to build
* Target audience and techstack

### Design
* It is decided by Senior Engineer/Engineering manager
* Defining the architecture
* Understanding and defining the techstack
* Monolith or microservice
* Hld and lld everything involved

### Development
* It is decided by SDE-1,2 in MNcs.

### Testing
* It is done by software Development Engineer Tester
* test the application thorough
* Writing test cases(part of development) like unit test cases and end to end test cases.

### Deployment
* It is done by Devops Engineer.
* managing servers.
* sometimes by developers generally depends upon company.

### Maintainance
* if there is any new requirement
* The above all phases done again here.
